# TanStack Router (apps/web)

- **`src/routeTree.gen.ts` is generated by the TanStack Vite plugin during `vite build` /
  `vite dev`** — it is not hand-edited. There is **no standalone CLI**: both
  `npx @tanstack/router-plugin generate-routes` and `pnpm exec tsr generate` fail. To regenerate
  after adding or moving a route file, run `pnpm --filter graflare-web build`.
- **Layout routes**: a route like `$id.tsx` that wraps children must render `<Outlet/>`; put the
  index page's content in `$id/index.tsx`, not in `$id.tsx`.
